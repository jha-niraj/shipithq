# Markdown Notes

Markdown notes that live in your browser, with fast search.

A React + TypeScript app made with Vite. Work through it one task at a time:
the brief for each task is in the **Task** tab, and **Check task** runs the
tests in `tests/` for the task you are on.

```bash
npm install
npm run dev     # the app
npm test        # the tests
```
